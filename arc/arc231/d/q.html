配点 : 700 点

問題文

この問題は インタラクティブな問題 (あなたの作成したプログラムとジャッジシステムが入出力を介して対話を行う形式の問題) です．

1 から N までの番号が付けられた N 個の山があります．また，それぞれの山には石が N - 1 個ずつあります．

これらを用いて先手と後手でゲームを行うことを考えます．ゲームでは先手から交互に手番を行います．

  • 先手は石が 1 つ以上存在する山を 1 個選ぶ．そこから 1 個以上 K 個以下の石を取り除く．
  • 後手は石が 1 つ以上存在する山を 1 個以上 K 個以下選ぶ．それらから石を 1 個ずつ取り除く．

先に操作ができなくなった方の負けです．あなたはこのゲームをジャッジと対戦します．まず，ジャッジにあなたが先手となるか後手となるかを宣言し，その後ゲームを行ってください．

制約

  • 2 \leq N \leq 200
  • 1 \leq K \leq N
  • 入力される値はすべて整数である

入出力

この問題はインタラクティブな問題 (あなたの作成したプログラムとジャッジシステムが入出力を介して対話を行う形式の問題) です．

最初に，N, K が以下の形式で与えられるので標準入力から受け取ってください．

N K

先手として対戦する場合

  • まず First を出力して改行してください．
  • 次に，ゲームが終了するまで以下のやり取りを繰り返してください．
    • まず，あなたが取る先手の行動を出力してください．山 i から石を j 個取り除く場合，i, j をこの順に空白区切りで出力して改行してください．
    • 次に，ジャッジが取る後手の行動を受け取ってください．まず，整数 k を受け取ってください．意味は以下の通りです．
      • k = -1: あなたがこの問題で不正解と判定されたことを示します．ただちにプログラムを終了してください．
      • k = 0: あなたがこの問題で正解と判定されたことを示します．ただちにプログラムを終了してください．
      • k > 0: 続いて，k 個の整数 a_1, a_2, \cdots, a_k が空白区切りで与えられます．これは，後手が山 a_1, a_2, \cdots, a_k から 1 個ずつ石を取り除くことを示します．

後手として対戦する場合

  • まず Second を出力して改行してください．
  • 次に，ゲームが終了するまで以下のやり取りを繰り返してください．
    • まず，ジャッジが取る先手の行動を受け取ってください．2 つの整数 i, j を受け取ってください．意味は以下の通りです．
      • i = -1: このとき，j = -1 です．あなたがこの問題で不正解と判定されたことを示します．ただちにプログラムを終了してください．
      • i = 0: このとき，j = 0 です．あなたがこの問題で正解と判定されたことを示します．ただちにプログラムを終了してください．
      • i > 0: これは，先手が山 i から j 個の石を取り除いたことを示します．
    • 次に，あなたが取る後手の行動を出力してください．山 a_1, a_2, \cdots, a_k から 1 個ずつ石を取り除く場合，まず k を出力して改行してください．その後，a_1, a_2, \cdots, a_k を空白区切りで出力して改行してください．

注意点

  • 出力を行うたびに，末尾に改行を入れて標準出力を flush してください．そうしなかった場合，ジャッジ結果が TLE となる可能性があります．
  • あなたがゲームで勝利した場合，正解と判定されます．
  • あなたがゲームで負けた場合，もしくは不正な出力を行なった場合，不正解と判定されます．
  • あなたがこの問題で正解もしくは不正解と判定されたことをジャッジから受け取ったら，ただちにプログラムを終了してください．そうしない場合，ジャッジ結果は不定です．
  • 余計な改行は不正なフォーマットの出力とみなされることに注意してください．

Problem Statement

This is an interactive problem (where your program interacts with the judge system via Standard Input and Output).

There are N piles numbered from 1 to N. Each pile has N - 1 stones.

Consider a game played by the first player and the second player using these. In the game, the players take turns alternately, starting with the first player.

  • The first player chooses one pile that has one or more stones, and removes between 1 and K stones, inclusive, from it.
  • The second player chooses between 1 and K piles, inclusive, each of which has one or more stones, and removes one stone from each of them.

The player who first becomes unable to make a move loses. You will play this game against the judge. First, declare to the judge whether you will be the first player or the second player, and then play the game.

Constraints

  • 2 \leq N \leq 200
  • 1 \leq K \leq N
  • All input values are integers.

Input and Output

This is an interactive problem (where your program interacts with the judge system via Standard Input and Output).

First, N and K are given in the following format; receive them from Standard Input.

N K

When playing as the first player

  • First, output First followed by a newline.
  • Then, repeat the following interaction until the game ends.
    • First, output your move as the first player. If you remove j stones from pile i, output i and j in this order, separated by a space, followed by a newline.
    • Next, receive the judge's move as the second player. First, receive an integer k. It means the following.
      • k = -1: This indicates that you have been judged as incorrect for this problem. Terminate your program immediately.
      • k = 0: This indicates that you have been judged as correct for this problem. Terminate your program immediately.
      • k > 0: Subsequently, k integers a_1, a_2, \cdots, a_k are given, separated by spaces. This indicates that the second player removes one stone from each of piles a_1, a_2, \cdots, a_k.

When playing as the second player

  • First, output Second followed by a newline.
  • Then, repeat the following interaction until the game ends.
    • First, receive the judge's move as the first player. Receive two integers i and j. They mean the following.
      • i = -1: In this case, j = -1. This indicates that you have been judged as incorrect for this problem. Terminate your program immediately.
      • i = 0: In this case, j = 0. This indicates that you have been judged as correct for this problem. Terminate your program immediately.
      • i > 0: This indicates that the first player removed j stones from pile i.
    • Next, output your move as the second player. If you remove one stone from each of piles a_1, a_2, \cdots, a_k, first output k followed by a newline. Then, output a_1, a_2, \cdots, a_k, separated by spaces, followed by a newline.

Notes

  • For each output, add a newline at the end and flush Standard Output. Otherwise, you may receive a TLE verdict.
  • If you win the game, you will be judged as correct.
  • If you lose the game, or if you make a malformed output, you will be judged as incorrect.
  • Once you receive from the judge that you have been judged correct or incorrect for this problem, terminate your program immediately. Otherwise, the verdict is indeterminate.
  • Note that extra newlines are considered as a malformed output.
