D - 均等な買い物 /

実行時間制限: 2 sec / メモリ制限: 1024 MiB

配点 : 400 点

問題文

高橋君と青木君がお土産を買いに行きます。お店は N 軒あり、1 から N までの番号が付けられています。i 番目のお店では、L_i 以上 R_i 以下の任意の整数金額で買い物ができます。

買い物計画とは、各お店に対して次のいずれか 1 つの状態を定めたものです。

  • 誰も買い物をしない。
  • 高橋君のみが買い物をし、そのお店で選べる範囲内の整数金額を 1 つ決める。
  • 青木君のみが買い物をし、そのお店で選べる範囲内の整数金額を 1 つ決める。

すなわち、同じお店で 2 人が同時に買い物をすることはできません。

買い物計画が以下の条件をすべて満たすとき、これを均等な買い物計画と呼びます。

  • 高橋君が買い物をするお店がちょうど P 軒である。
  • 青木君が買い物をするお店がちょうど Q 軒である。
  • 高橋君の合計購入金額と青木君の合計購入金額が等しい。

2 つの買い物計画が異なるとは、少なくとも 1 つのお店について以下のいずれかが成り立つことをいいます。

  • そのお店の状態（誰も買い物をしない・高橋君が買い物をする・青木君が買い物をする）が異なる。
  • そのお店で同じ人が買い物をしているが、選んだ購入金額が異なる。

これから M 回、お店の購入金額範囲の変更が順に行われます。j 回目の変更では、X_j 番目のお店で選べる購入金額の範囲が A_j 以上 B_j 以下に置き換わります。変更は累積的に適用されます（過去の変更の結果は保持されたまま、新たな変更が適用されます）。

各変更の直後における、均等な買い物計画の個数を 998244353 で割った余りを求めてください。

制約

  • 1 \leq N \leq 2000
  • 1 \leq P \leq 3
  • 1 \leq Q \leq 3
  • P + Q \leq N
  • 1 \leq M \leq 1000
  • N \times M \leq 2000
  • 1 \leq L_i \leq R_i \leq 20
  • 1 \leq X_j \leq N
  • 1 \leq A_j \leq B_j \leq 20
  • 入力はすべて整数である。

入力

N P Q M
L_1 R_1
L_2 R_2
\vdots
L_N R_N
X_1 A_1 B_1
X_2 A_2 B_2
\vdots
X_M A_M B_M
  • 1 行目には、お店の数 N、高橋君が買い物をするお店の数 P、青木君が買い物をするお店の数 Q、変更の回数 M が、スペース区切りで与えられる。
  • 続く N 行のうち i 行目には、i 番目のお店で初期状態において選べる最小金額 L_i と最大金額 R_i が、スペース区切りで与えられる。
  • 続く M 行のうち j 行目には、j 回目の変更対象のお店の番号 X_j、新しい範囲の下限 A_j、上限 B_j が、スペース区切りで与えられる。この変更により、X_j 番目のお店で選べる購入金額の範囲は A_j 以上 B_j 以下に置き換わる。

出力

M 行出力せよ。j 行目には、j 回目の変更の直後における均等な買い物計画の個数を 998244353 で割った余りを出力せよ。

Problem Statement

Takahashi and Aoki are going shopping for souvenirs. There are N shops, numbered from 1 to N. At the i-th shop, one can purchase items for any integer amount between L_i and R_i, inclusive.

A shopping plan assigns exactly one of the following states to each shop:

  • Nobody shops there.
  • Only Takahashi shops there, and he chooses one integer amount within the shop's allowed range.
  • Only Aoki shops there, and he chooses one integer amount within the shop's allowed range.

That is, two people cannot shop at the same shop simultaneously.

A shopping plan is called an equal shopping plan if it satisfies all of the following conditions:

  • Takahashi shops at exactly P shops.
  • Aoki shops at exactly Q shops.
  • Takahashi's total purchase amount equals Aoki's total purchase amount.

Two shopping plans are considered different if there exists at least one shop for which one of the following holds:

  • The state of that shop (nobody shops / Takahashi shops / Aoki shops) differs between the two plans.
  • The same person shops at that shop in both plans, but the chosen purchase amount differs.

From now on, M changes to the shops' price ranges will be applied in order. In the j-th change, the allowed purchase amount range at shop X_j is replaced with A_j to B_j, inclusive. Changes are applied cumulatively (the results of past changes are retained, and new changes are applied on top of them).

After each change, find the number of equal shopping plans modulo 998244353.

Constraints

  • 1 \leq N \leq 2000
  • 1 \leq P \leq 3
  • 1 \leq Q \leq 3
  • P + Q \leq N
  • 1 \leq M \leq 1000
  • N \times M \leq 2000
  • 1 \leq L_i \leq R_i \leq 20
  • 1 \leq X_j \leq N
  • 1 \leq A_j \leq B_j \leq 20
  • All input values are integers.

Input

N P Q M
L_1 R_1
L_2 R_2
\vdots
L_N R_N
X_1 A_1 B_1
X_2 A_2 B_2
\vdots
X_M A_M B_M
  • The first line contains the number of shops N, the number of shops where Takahashi shops P, the number of shops where Aoki shops Q, and the number of changes M, separated by spaces.
  • The following N lines, where the i-th line contains the minimum amount L_i and maximum amount R_i available at the i-th shop in the initial state, separated by spaces.
  • The following M lines, where the j-th line contains the shop number X_j targeted by the j-th change, the new lower bound A_j, and upper bound B_j, separated by spaces. This change replaces the allowed purchase amount range at shop X_j with A_j to B_j, inclusive.

Output

Output M lines. The j-th line should contain the number of equal shopping plans immediately after the j-th change, modulo 998244353.
