E - 粒子の拡散シミュレーション 解説 /

実行時間制限: 2 sec / メモリ制限: 1024 MiB

配点 : 466 点

問題文

高橋君は物理シミュレータを開発しています。シミュレータでは、N 個の容器が接続されたネットワーク上で粒子がどのように拡散するかを計算します。

容器には 1 から N までの番号が付けられています。各容器では「正の電荷を持つ粒子の量」と「負の電荷を持つ粒子の量」がそれぞれ非負の有理数として管理されます。

遷移の割合

粒子の遷移の比率を定める N \times N の非負整数行列 R が与えられます。R_{i,j} は容器 i から容器 j への遷移の重みを表します。各 i（1 \leq i \leq N）について、行和 \displaystyle\sum_{j=1}^{N} R_{i,j} は 1 以上であることが保証されます（R_{i,j} は非負整数なので、これは行和が正であることと同値です）。

容器 i にある粒子のうち、容器 j へ遷移する割合 P_{i,j} は次の式で定まります：

P_{i,j} = \frac{R_{i,j}}{\displaystyle\sum_{j'=1}^{N} R_{i,j'}}

j = i の場合も含みます。P_{i,i} > 0 のとき、粒子の一部は容器 i にそのまま留まります。P_{i,j} = 0 のとき、容器 i から容器 j への遷移量は 0 です。

電荷の反転

粒子には「正」と「負」の 2 つの電荷の状態があります。容器間を遷移する際に電荷が反転する経路が存在します。具体的には、M 個の「反転ルール」(u_k, v_k)（1 \leq k \leq M、u_k \neq v_k）が与えられます。容器 u_k から容器 v_k へ粒子が遷移する際、その粒子の電荷は反転します（正→負、負→正）。

反転ルールは有向です。(u, v) が与えられていても (v, u) が与えられていなければ、v から u への遷移では電荷は反転しません。反転ルールが指定されていない遷移では電荷は変化しません。u_k \neq v_k が保証されるため、容器 i にそのまま留まる粒子（j = i の遷移）に対して反転ルールが設定されることはなく、留まる粒子の電荷は常に変化しません。

なお、R_{i,j} = 0（すなわち P_{i,j} = 0）である組 (i, j) に対して反転ルールが存在する場合もありますが、遷移量が 0 であるため結果に影響しません。

1ステップの更新

1ステップの更新は、すべての容器の更新前の値をもとに同時に行われます。すなわち、各容器の新しい値は、すべての容器の更新前の値のみから計算されます。

ステップ開始時に容器 i に正の電荷を持つ粒子が量 x_i^{+}、負の電荷を持つ粒子が量 x_i^{-} だけあるとします。

各容器 i から各容器 j へ、正の粒子は量 x_i^{+} \times P_{i,j}、負の粒子は量 x_i^{-} \times P_{i,j} がそれぞれ遷移します。遷移の際、反転ルール (i, j) が存在すれば、その遷移分の電荷は反転します（正の粒子は負の粒子として到着し、負の粒子は正の粒子として到着します）。反転ルールが存在しなければ電荷はそのまま保たれます。

これを数式で表します。F_{i,j} を、反転ルール (i, j) が存在するとき 1、存在しないとき 0 とします。更新後の容器 j の正の粒子の量 y_j^{+} および負の粒子の量 y_j^{-} は、すべての容器 i（1 \leq i \leq N）からの到着分を合算して次のように求められます：

y_j^{+} = \sum_{i=1}^{N} \Bigl( (1 - F_{i,j}) \cdot x_i^{+} \cdot P_{i,j} + F_{i,j} \cdot x_i^{-} \cdot P_{i,j} \Bigr)

y_j^{-} = \sum_{i=1}^{N} \Bigl( (1 - F_{i,j}) \cdot x_i^{-} \cdot P_{i,j} + F_{i,j} \cdot x_i^{+} \cdot P_{i,j} \Bigr)

初期状態と求める値

初期状態（ステップ 0 の開始時点）では、容器 S に正の電荷を持つ粒子がちょうど 1 単位だけ存在し、それ以外（他のすべての容器の正の粒子の量、およびすべての容器の負の粒子の量）はすべて 0 です。

T ステップ後（T 回の更新操作が完了した後）に、容器 G にある正の電荷を持つ粒子の量を求めてください。

出力形式について

求める値は非負の有理数です。この値を既約分数 \frac{p}{q}（p \geq 0、q > 0、\gcd(p, q) = 1）で表したとき、q と 10^9 + 7 は互いに素であることが保証されます。10^9 + 7 は素数です。q \times r \equiv p \pmod{10^9 + 7} を満たす整数 r（0 \leq r < 10^9 + 7）が一意に存在するので、この r を出力してください。

制約

  • 1 \leq N \leq 30
  • 0 \leq M \leq N \times (N - 1)
  • 1 \leq T \leq 10^{18}
  • 1 \leq S \leq N
  • 1 \leq G \leq N
  • 0 \leq R_{i,j} \leq 10^6（1 \leq i, j \leq N）
  • R_{i,j} は整数である
  • すべての i（1 \leq i \leq N）に対して \displaystyle\sum_{j=1}^{N} R_{i,j} \geq 1
  • 1 \leq u_k \leq N、1 \leq v_k \leq N、u_k \neq v_k（1 \leq k \leq M）
  • 反転ルール (u_k, v_k) はすべて異なる（同じ有向の組が複数回与えられることはない）
  • 入力はすべて整数である

Problem Statement

Takahashi is developing a physics simulator. In this simulator, he calculates how particles diffuse over a network of N connected containers.

The containers are numbered 1 to N. In each container, the "amount of positively charged particles" and the "amount of negatively charged particles" are managed as non-negative rational numbers.

Transition Ratios

You are given an N \times N non-negative integer matrix R that determines the ratios of particle transitions. R_{i,j} represents the weight of the transition from container i to container j. For each i (1 \leq i \leq N), it is guaranteed that the row sum \displaystyle\sum_{j=1}^{N} R_{i,j} is at least 1 (since R_{i,j} are non-negative integers, this is equivalent to the row sum being positive).

The ratio P_{i,j} of particles in container i that transition to container j is determined by the following formula:

P_{i,j} = \frac{R_{i,j}}{\displaystyle\sum_{j'=1}^{N} R_{i,j'}}

This includes the case where j = i. When P_{i,i} > 0, a fraction of the particles remain in container i. When P_{i,j} = 0, the amount of transition from container i to container j is 0.

Charge Inversion

Particles have two charge states: "positive" and "negative". There are certain paths where the charge of a particle is inverted during transition. Specifically, you are given M "inversion rules" (u_k, v_k) (1 \leq k \leq M, u_k \neq v_k). When a particle transitions from container u_k to container v_k, its charge is inverted (positive \to negative, negative \to positive).

Inversion rules are directed. Even if (u, v) is given, if (v, u) is not given, the charge is not inverted during a transition from v to u. For transitions where no inversion rule is specified, the charge does not change. Since u_k \neq v_k is guaranteed, no inversion rule will be set for particles remaining in container i (the transition j = i), so the charge of remaining particles never changes.

Note that an inversion rule may exist for a pair (i, j) where R_{i,j} = 0 (i.e., P_{i,j} = 0), but since the transition amount is 0, it does not affect the result.

1-Step Update

A 1-step update is performed simultaneously based on the values of all containers before the update. That is, the new value of each container is calculated using only the pre-update values of all containers.

Suppose that at the start of a step, container i contains an amount x_i^{+} of positively charged particles and an amount x_i^{-} of negatively charged particles.

From each container i to each container j, an amount x_i^{+} \times P_{i,j} of positive particles and x_i^{-} \times P_{i,j} of negative particles transition, respectively. During the transition, if an inversion rule (i, j) exists, the charge of this transitioning portion is inverted (positive particles arrive as negative particles, and negative particles arrive as positive particles). If no inversion rule exists, the charge is preserved.

To express this mathematically, let F_{i,j} be 1 if an inversion rule (i, j) exists, and 0 otherwise. The updated amount of positive particles y_j^{+} and negative particles y_j^{-} in container j are calculated by summing the arrivals from all containers i (1 \leq i \leq N) as follows:

y_j^{+} = \sum_{i=1}^{N} \Bigl( (1 - F_{i,j}) \cdot x_i^{+} \cdot P_{i,j} + F_{i,j} \cdot x_i^{-} \cdot P_{i,j} \Bigr)

y_j^{-} = \sum_{i=1}^{N} \Bigl( (1 - F_{i,j}) \cdot x_i^{-} \cdot P_{i,j} + F_{i,j} \cdot x_i^{+} \cdot P_{i,j} \Bigr)

Initial State and Target Value

In the initial state (at the start of step 0), there is exactly 1 unit of positively charged particles in container S, and all other amounts (the amount of positive particles in all other containers, and the amount of negative particles in all containers) are 0.

Find the amount of positively charged particles in container G after T steps (after T update operations have been completed).

Output Format Note

The value to be found is a non-negative rational number. When this value is represented as an irreducible fraction \frac{p}{q} (p \geq 0, q > 0, \gcd(p, q) = 1), it is guaranteed that q and 10^9 + 7 are coprime. Note that 10^9 + 7 is a prime number. There exists a unique integer r (0 \leq r < 10^9 + 7) such that q \times r \equiv p \pmod{10^9 + 7}. Output this r.

Constraints

  • 1 \leq N \leq 30
  • 0 \leq M \leq N \times (N - 1)
  • 1 \leq T \leq 10^{18}
  • 1 \leq S \leq N
  • 1 \leq G \leq N
  • 0 \leq R_{i,j} \leq 10^6 (1 \leq i, j \leq N)
  • R_{i,j} is an integer.
  • For all i (1 \leq i \leq N), \displaystyle\sum_{j=1}^{N} R_{i,j} \geq 1
  • 1 \leq u_k \leq N, 1 \leq v_k \leq N, u_k \neq v_k (1 \leq k \leq M)
  • All inversion rules (u_k, v_k) are distinct (the same directed pair will not be given multiple times).
  • All input values are integers.
