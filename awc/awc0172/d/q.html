D - リレー配送と日替わり手数料 /

実行時間制限: 2 sec / メモリ制限: 1024 MiB

配点 : 400 点

問題文

高橋君は、一本道上にある N 個の届け先に荷物を届けるため、リレー方式の配送を計画します。届け先には出発地点から近い順に 1, 2, \ldots, N の番号が付いており、届け先 i は出発地点から距離 X_i の位置にあります。便宜上、出発地点の位置を X_0 = 0 とおきます。

配達員が N 人おり、0, 1, \ldots, N-1 の番号が付いています。配達員 j は位置 X_j に待機しています（すなわち、配達員 0 は出発地点に、配達員 j（j \geq 1）は届け先 j の位置にいます）。

配達員 j が起用される場合、届け先 j+1 から始まる連続する k 個の届け先（届け先 j+1, j+2, \ldots, j+k）に荷物を届けます。ここで k は担当件数であり、L_j \le k \le R_j を満たす必要があります。配達員 j は位置 X_j から位置 X_{j+k} まで移動し、そこで次の配達員に荷物を引き継ぎます。このときの費用は

A_j (X_{j+k} - X_j) + B_j

です。

配送計画 とは、整数の狭義単調増加列

0 = p_0 < p_1 < \cdots < p_m = N

であって、各 t = 1, 2, \ldots, m について

L_{p_{t-1}} \le p_t - p_{t-1} \le R_{p_{t-1}}

を満たすものです。この配送計画では、配達員 p_0, p_1, \ldots, p_{m-1} の m 人が順に起用され、配達員 p_{t-1} が届け先 p_{t-1}+1 から届け先 p_t までを担当します。起用されない配達員には費用は発生しません。

高橋君は Q 日間にわたって配送を行います。日 q には、配達員を 1 人起用するたびに追加手数料 C_q がかかります。したがって、日 q に配送計画 0 = p_0 < p_1 < \cdots < p_m = N を使ったときの総費用は

\displaystyle \sum_{t=1}^{m} \left( A_{p_{t-1}} (X_{p_t} - X_{p_{t-1}}) + B_{p_{t-1}} \right) + m \cdot C_q

です。配送計画は日ごとに独立に選ぶことができます。

各日について、すべての届け先に荷物を届ける実行可能な配送計画が存在する場合はその総費用の最小値を出力してください。存在しない場合は -1 を出力してください。

なお、配送計画の実行可能性は C_q の値に依存しないため、実行可能な配送計画が存在しない場合はすべての日について -1 となります。

制約

  • 1 \leq N \leq 500
  • 1 \leq Q \leq 2 \times 10^5
  • NQ \leq 2 \times 10^7
  • 1 \leq X_1 < X_2 < \cdots < X_N \leq 10^9
  • 1 \leq L_j \leq R_j \leq N（0 \leq j \leq N-1）
  • 1 \leq A_j \leq 10^6（0 \leq j \leq N-1）
  • 0 \leq B_j \leq 10^9（0 \leq j \leq N-1）
  • 0 \leq C_q \leq 10^9（1 \leq q \leq Q）
  • 入力はすべて整数である。

入力

N Q
X_1 X_2 \ldots X_N
L_0 R_0 A_0 B_0
L_1 R_1 A_1 B_1
\vdots
L_{N-1} R_{N-1} A_{N-1} B_{N-1}
C_1 C_2 \ldots C_Q
  • 1 行目には、届け先の個数を表す整数 N と、日数を表す整数 Q がスペース区切りで与えられる。
  • 2 行目には、届け先の位置を表す整数 X_1, X_2, \ldots, X_N がスペース区切りで与えられる。
  • 3 + j 行目（0 \le j \le N-1）には、配達員 j の担当件数の下限 L_j、上限 R_j、費用の距離係数 A_j、固定費用 B_j を表す整数がスペース区切りで与えられる。
  • 最後の行には、各日の追加手数料を表す整数 C_1, C_2, \ldots, C_Q がスペース区切りで与えられる。

出力

q 行目には、日 q における総費用の最小値を出力せよ。実行可能な配送計画が存在しない場合は -1 を出力せよ。

Problem Statement

Takahashi plans a relay-style delivery to deliver packages to N destinations along a straight road. The destinations are numbered 1, 2, \ldots, N in order of increasing distance from the starting point, and destination i is located at distance X_i from the starting point. For convenience, let X_0 = 0 denote the position of the starting point.

There are N couriers, numbered 0, 1, \ldots, N-1. Courier j is stationed at position X_j (that is, courier 0 is at the starting point, and courier j (j \geq 1) is at the position of destination j).

If courier j is employed, they deliver packages to k consecutive destinations starting from destination j+1 (i.e., destinations j+1, j+2, \ldots, j+k). Here, k is the number of assigned deliveries and must satisfy L_j \le k \le R_j. Courier j travels from position X_j to position X_{j+k}, where they hand off the packages to the next courier. The cost incurred is

A_j (X_{j+k} - X_j) + B_j

A delivery plan is a strictly increasing sequence of integers

0 = p_0 < p_1 < \cdots < p_m = N

such that for each t = 1, 2, \ldots, m,

L_{p_{t-1}} \le p_t - p_{t-1} \le R_{p_{t-1}}

is satisfied. In this delivery plan, the m couriers p_0, p_1, \ldots, p_{m-1} are employed in order, and courier p_{t-1} is responsible for destinations p_{t-1}+1 through p_t. No cost is incurred for couriers that are not employed.

Takahashi carries out deliveries over Q days. On day q, an additional surcharge of C_q is incurred each time a courier is employed. Therefore, the total cost of using delivery plan 0 = p_0 < p_1 < \cdots < p_m = N on day q is

\displaystyle \sum_{t=1}^{m} \left( A_{p_{t-1}} (X_{p_t} - X_{p_{t-1}}) + B_{p_{t-1}} \right) + m \cdot C_q

The delivery plan can be chosen independently for each day.

For each day, if there exists a feasible delivery plan that delivers packages to all destinations, output the minimum total cost. If no feasible plan exists, output -1.

Note that the feasibility of a delivery plan does not depend on the value of C_q, so if no feasible delivery plan exists, the answer is -1 for all days.

Constraints

  • 1 \leq N \leq 500
  • 1 \leq Q \leq 2 \times 10^5
  • NQ \leq 2 \times 10^7
  • 1 \leq X_1 < X_2 < \cdots < X_N \leq 10^9
  • 1 \leq L_j \leq R_j \leq N (0 \leq j \leq N-1)
  • 1 \leq A_j \leq 10^6 (0 \leq j \leq N-1)
  • 0 \leq B_j \leq 10^9 (0 \leq j \leq N-1)
  • 0 \leq C_q \leq 10^9 (1 \leq q \leq Q)
  • All input values are integers.

Input

N Q
X_1 X_2 \ldots X_N
L_0 R_0 A_0 B_0
L_1 R_1 A_1 B_1
\vdots
L_{N-1} R_{N-1} A_{N-1} B_{N-1}
C_1 C_2 \ldots C_Q
  • The first line contains two integers N and Q, separated by a space, representing the number of destinations and the number of days, respectively.
  • The second line contains N integers X_1, X_2, \ldots, X_N, separated by spaces, representing the positions of the destinations.
  • The (3 + j)-th line (0 \le j \le N-1) contains four integers separated by spaces: the minimum number of deliveries L_j, the maximum number of deliveries R_j, the distance cost coefficient A_j, and the fixed cost B_j for courier j.
  • The last line contains Q integers C_1, C_2, \ldots, C_Q, separated by spaces, representing the additional surcharge for each day.

Output

Output Q lines.

On the q-th line, output the minimum total cost on day q. If no feasible delivery plan exists, output -1.
