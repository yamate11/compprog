E - 割引クーポンの旅 /

実行時間制限: 2 sec / メモリ制限: 1024 MiB

配点 : 433 点

問題文

高橋君は、N 個の都市を結ぶ交通網を使って旅行をしようとしています。

都市には 1 から N までの番号が付けられています。都市間を結ぶ M 本の道路があり、i 番目の道路は都市 U_i と都市 V_i を双方向に結んでおり、通行料金が W_i 円かかります。ただし、自己ループ（同じ都市同士を結ぶ道路）は存在しません。同じ都市の組を結ぶ道路が複数存在することはあります。

各都市には観光案内所があり、都市 j の観光案内所では P_j 円分の割引クーポンを配布しています。高橋君がある都市に滞在するたびに（出発地点である都市 1 も含めて）、その都市の観光案内所からクーポンを受け取ることができます。同じ都市を複数回訪れた場合は、訪れるたびに毎回受け取れます。

高橋君は都市 1 から出発し、道路を通って都市 N に到着したいと考えています。高橋君の移動経路は、都市の列 v_0, v_1, \ldots, v_k（ただし v_0 = 1, v_k = N, k \geq 1）と、各 t = 1, 2, \ldots, k について v_{t-1} と v_t を結ぶ道路 e_t の選択によって定まります。経路の長さ k に上限はなく、同じ道路や同じ都市を何度通ってもかまいません。

高橋君が支払う実質費用は次の式で定まります。

\text{実質費用} = \sum_{t=1}^{k} W_{e_t} - \sum_{t=0}^{k} P_{v_t}

すなわち、経路上で通った各道路の通行料金の合計（同じ道路を複数回通った場合はその回数分加算）から、経路上で訪れた各都市で受け取ったクーポンの額の合計（出発地点の都市 1 と到着地点の都市 N を含み、同じ都市を複数回訪れた場合は訪問回数分だけ加算）を引いた値です。実質費用は負の値になることもあります。

都市 1 から都市 N へ到達可能であることは保証されます。高橋君が最適な経路を選んだときの実質費用の最小値を求めてください。ただし、任意の整数 X に対して実質費用が X 以下となる経路が存在する（すなわち、実質費用をいくらでも小さくできる）場合は -inf と出力してください。

制約

  • 2 \leq N \leq 2 \times 10^5
  • 1 \leq M \leq 2 \times 10^5
  • 0 \leq P_j \leq 10^9 (1 \leq j \leq N)
  • 1 \leq U_i, V_i \leq N (1 \leq i \leq M)
  • U_i \neq V_i (1 \leq i \leq M)
  • 1 \leq W_i \leq 10^9 (1 \leq i \leq M)
  • 都市 1 から都市 N へ到達可能である
  • 入力はすべて整数である

入力

N M
P_1 P_2 \ldots P_N
U_1 V_1 W_1
U_2 V_2 W_2
\vdots
U_M V_M W_M
  • 1 行目には、都市の数を表す整数 N と道路の数を表す整数 M が、スペース区切りで与えられる。
  • 2 行目には、各都市で受け取れる割引クーポンの額を表す整数 P_1, P_2, \ldots, P_N が、スペース区切りで与えられる。
  • 3 行目から M 行にわたって、道路の情報が与えられる。
  • 2 + i 行目では、i 番目の道路が結ぶ都市の番号 U_i, V_i と通行料金 W_i が、スペース区切りで与えられる。

出力

実質費用の最小値を 1 行で出力せよ。ただし、実質費用をいくらでも小さくできる場合は -inf と出力せよ（バッククォート内の文字列をそのまま、すべて小文字で出力すること）。

Problem Statement

Takahashi is planning a trip using a transportation network connecting N cities.

The cities are numbered 1 to N. There are M bidirectional roads connecting the cities. The i-th road connects city U_i and city V_i bidirectionally and costs W_i yen. There are no self-loops (roads connecting a city to itself). There may be multiple roads connecting the same pair of cities.

Each city has a tourist information center, and the center in city j distributes discount coupons worth P_j yen. Every time Takahashi visits a city (including the starting city 1), he can receive a coupon from that city's tourist information center. If he visits the same city multiple times, he receives a coupon every time he visits.

Takahashi wants to start from city 1 and reach city N by traveling along the roads. Takahashi's path is determined by a sequence of cities v_0, v_1, \ldots, v_k (where v_0 = 1, v_k = N, and k \geq 1) and a choice of road e_t connecting v_{t-1} and v_t for each t = 1, 2, \ldots, k. There is no upper limit on the path length k, and he can traverse the same road or visit the same city multiple times.

The net cost Takahashi pays is determined by the following formula:

\text{Net Cost} = \sum_{t=1}^{k} W_{e_t} - \sum_{t=0}^{k} P_{v_t}

In other words, it is the total toll of the roads traversed along the path (counted multiple times if traversed multiple times) minus the total value of the coupons received at the cities visited along the path (including the starting city 1 and the destination city N, counted multiple times if visited multiple times). The net cost can be negative.

It is guaranteed that city N is reachable from city 1. Find the minimum possible net cost when Takahashi chooses an optimal path. However, if there exists a path such that the net cost is at most X for any integer X (i.e., the net cost can be made arbitrarily small), output -inf.

Constraints

  • 2 \leq N \leq 2 \times 10^5
  • 1 \leq M \leq 2 \times 10^5
  • 0 \leq P_j \leq 10^9 (1 \leq j \leq N)
  • 1 \leq U_i, V_i \leq N (1 \leq i \leq M)
  • U_i \neq V_i (1 \leq i \leq M)
  • 1 \leq W_i \leq 10^9 (1 \leq i \leq M)
  • City N is reachable from city 1.
  • All input values are integers.

Input

N M
P_1 P_2 \ldots P_N
U_1 V_1 W_1
U_2 V_2 W_2
\vdots
U_M V_M W_M
  • The first line contains an integer N representing the number of cities and an integer M representing the number of roads, separated by a space.
  • The second line contains integers P_1, P_2, \ldots, P_N representing the values of the discount coupons available at each city, separated by spaces.
  • The next M lines provide the information about the roads.
  • The (2 + i)-th line contains the city numbers U_i and V_i connected by the i-th road, and its toll W_i, separated by spaces.

Output

Print the minimum net cost in a single line. If the net cost can be made arbitrarily small, print -inf (exactly as written in lowercase).
