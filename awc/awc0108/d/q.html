D - セキュリティエリアの突破 解説 /

実行時間制限: 2 sec / メモリ制限: 1024 MiB

この問題には不備があり、現在正しいジャッジが行われていません。(2026/07/08 23:35)

問題文

高橋君は N 個の区画からなるセキュリティエリアに侵入テストを行っています。各区画には 1 から N までの番号が付けられており、区画 1 が入口、区画 N が目的地です。

セキュリティエリアには M 本の一方通行の通路があり、i 番目の通路（1 \leq i \leq M）は区画 U_i から区画 V_i へ移動できます。各通路にはセキュリティゲートが設置されており、i 番目の通路を通過するには種類 K_i の IDカードを所持している必要があります。

IDカードの種類は 1 以上 N 以下の整数で表されます。高橋君の IDカードの所持状態は「各種類について、所持しているか否か」で管理されます。すなわち、ある種類の IDカードを一度入手すれば、以降はその種類を所持している状態が維持され、使用しても失われません。同じ種類の IDカードを複数回入手しても、所持状態は変わりません。

各区画には端末が設置されていることがあります。区画 j（1 \leq j \leq N）について、P_j = 1 のとき端末があり、P_j = 0 のとき端末がありません。端末がある区画 j に高橋君がいるとき、その端末をハッキングして種類 C_j の IDカードを入手できます。ただし、各区画の端末はそれぞれ一度だけハッキングでき、同じ区画に複数回訪れても 2 回目以降はハッキングできません。端末がない区画（P_j = 0）では IDカードは手に入りません。

高橋君がある区画にいるとき、以下の行動を好きな順序で何度でも行うことができます。

  • 端末のハッキング：現在いる区画にまだハッキングしていない端末がある場合、それをハッキングして IDカードを入手する。
  • 通路の移動：現在いる区画から出ている通路のうち、通過に必要な種類の IDカードを所持しているものを 1 つ選び、その通路を通って別の区画へ移動する。

高橋君は最初、区画 1（入口）にいて、IDカードを 1 枚も持っていません。区画 1 に端末がある場合、開始直後にその端末をハッキングすることもできます。高橋君は同じ区画や同じ通路を何度でも訪れたり通ったりできます。

なお、同じ始点と終点を持つ通路が複数存在することがあります（必要な IDカードの種類が同じ場合も含みます）。

高橋君が区画 N（目的地）に到達できるかどうかを判定してください。到達できる場合は Yes を、できない場合は No を出力してください。

制約

  • 2 \leq N \leq 10^5
  • 0 \leq M \leq 10^5
  • P_j \in \{0, 1\} \quad (1 \leq j \leq N)
  • P_j = 1 のとき 1 \leq C_j \leq N
  • P_j = 0 のとき C_j = 0
  • 1 \leq U_i \leq N \quad (1 \leq i \leq M)
  • 1 \leq V_i \leq N \quad (1 \leq i \leq M)
  • U_i \neq V_i \quad (1 \leq i \leq M)
  • 1 \leq K_i \leq N \quad (1 \leq i \leq M)
  • 入力はすべて整数である

Problem Statement

Takahashi is conducting a penetration test on a security area consisting of N sections. Each section is numbered from 1 to N, where section 1 is the entrance and section N is the destination.

The security area has M one-way passages. The i-th passage (1 \leq i \leq M) allows movement from section U_i to section V_i. Each passage has a security gate installed, and to pass through the i-th passage, one must possess an ID card of type K_i.

ID card types are represented by integers from 1 to N. Takahashi's ID card possession state is managed as "whether or not he possesses each type." That is, once he obtains an ID card of a certain type, he continues to possess that type from then on, and it is not lost upon use. Obtaining the same type of ID card multiple times does not change the possession state.

Each section may have a terminal installed. For section j (1 \leq j \leq N), if P_j = 1 there is a terminal, and if P_j = 0 there is no terminal. When Takahashi is at a section j that has a terminal, he can hack the terminal to obtain an ID card of type C_j. However, the terminal in each section can be hacked only once; even if he visits the same section multiple times, he cannot hack it a second time or later. At sections without terminals (P_j = 0), no ID cards can be obtained.

When Takahashi is at a section, he can perform the following actions in any order, any number of times:

  • Hack a terminal: If there is a terminal in the current section that has not yet been hacked, hack it to obtain an ID card.
  • Move through a passage: Choose one of the passages leading out of the current section for which he possesses the required type of ID card, and move to another section through that passage.

Initially, Takahashi is at section 1 (the entrance) and possesses no ID cards. If section 1 has a terminal, he can hack it immediately after starting. Takahashi can visit the same section or traverse the same passage any number of times.

Note that there may be multiple passages with the same starting and ending points (including cases where the required ID card types are the same).

Determine whether Takahashi can reach section N (the destination). If he can, output Yes; otherwise, output No.

Constraints

  • 2 \leq N \leq 10^5
  • 0 \leq M \leq 10^5
  • P_j \in \{0, 1\} \quad (1 \leq j \leq N)
  • When P_j = 1: 1 \leq C_j \leq N
  • When P_j = 0: C_j = 0
  • 1 \leq U_i \leq N \quad (1 \leq i \leq M)
  • 1 \leq V_i \leq N \quad (1 \leq i \leq M)
  • U_i \neq V_i \quad (1 \leq i \leq M)
  • 1 \leq K_i \leq N \quad (1 \leq i \leq M)
  • All input values are integers

Input

N M
P_1 C_1
P_2 C_2
\vdots
P_N C_N
U_1 V_1 K_1
U_2 V_2 K_2
\vdots
U_M V_M K_M
  • The first line contains the number of sections N and the number of passages M, separated by a space.
  • The following N lines give the terminal information for each section. The j-th of these lines (line 1 + j overall) contains P_j, indicating whether section j has a terminal, and C_j, the type of ID card obtained by hacking it, separated by a space. When P_j = 0, C_j = 0 is given, but since there is no terminal, no ID card can be obtained.
  • The following M lines give the information for each passage. The i-th of these lines (line N + 1 + i overall) contains the starting point U_i, the ending point V_i, and the required ID card type K_i for the i-th passage, separated by spaces.

Output

If Takahashi can reach section N from section 1, output Yes; otherwise, output No on a single line.
