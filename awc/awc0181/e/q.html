E - 図書館の座席案内 /

実行時間制限: 2 sec / メモリ制限: 1024 MiB

配点 : 433 点

問題文

高橋君は図書館の管理システムを担当しています。図書館には一列に並んだ N 個の座席があり、左から順に 1, 2, \ldots, N と番号が付けられています。各座席は長テーブルに面しており、1 つの座席に複数の利用者が同時に座ることもできます。

これから M 人の利用者が順番に図書館を訪れます。i 番目 (1 \leq i \leq M) の利用者は時刻 S_i に到着し、座席 L_i から座席 R_i までの連続する区間の中から座席を 1 つ選んで座ります。利用者は一度座ると時刻 T まで座席を離れません。すなわち、各座席に座っている人数は時間とともに単調に増加します。

座席の選び方は以下のとおりです。同じ時刻に複数の利用者が到着する場合も、入力で与えられた順（i が小さい順）に 1 人ずつ処理します。

  • 1 番目から i-1 番目までの利用者がすべて着席した後の状態において、座席 L_i, L_i+1, \ldots, R_i の中で座っている利用者の人数が最も少ない座席を選ぶ。
  • そのような座席が複数ある場合は、番号が最も小さい座席を選ぶ。

利用者が座席に座ると、図書館のスタッフはその利用者の手元を照らすために卓上ライトを 1 つ新たに点灯させます。すなわち、利用者 1 人につきライトがちょうど 1 つ、その利用者が着席した座席で、到着時刻に点灯します。

i 番目の利用者のために時刻 S_i に点灯されたライトの、時刻 T_0（ただし T_0 \geq S_i）における明るさは

\max(100 - (T_0 - S_i),\ 0)

です。つまり、点灯した瞬間の明るさは 100 で、時刻が 1 進むごとに明るさが 1 ずつ減少し、点灯から 100 以上の時間が経過すると明るさは 0 になります。

高橋君は、ある時刻 T における各座席のライトの明るさの合計を知りたいと思っています。各座席 1, 2, \ldots, N について、その座席で点灯しているすべてのライトの時刻 T における明るさの合計を求めてください。ライトが 1 つも点灯していない座席や、すべてのライトの明るさが 0 になった座席については、明るさの合計は 0 です。

制約

  • 1 \leq N \leq 2 \times 10^5
  • 1 \leq M \leq 2 \times 10^5
  • 0 \leq T \leq 10^9
  • 0 \leq S_i \leq T
  • 1 \leq L_i \leq R_i \leq N
  • S_1 \leq S_2 \leq \cdots \leq S_M
  • 入力はすべて整数である

入力

N M T
S_1 L_1 R_1
S_2 L_2 R_2
\vdots
S_M L_M R_M
  • 1 行目には、座席の数を表す整数 N、利用者の人数を表す整数 M、明るさを確認する時刻を表す整数 T が、スペース区切りで与えられる。
  • 続く M 行のうち i 行目 (1 \leq i \leq M) には、i 番目の利用者の到着時刻 S_i、希望する座席区間の左端 L_i、右端 R_i が、スペース区切りで与えられる。
  • 利用者の情報は到着時刻 S_i の昇順（非減少順）に与えられる。

出力

N 個の整数をスペース区切りで 1 行に出力せよ。j 番目 (1 \leq j \leq N) の整数は、時刻 T における座席 j のライトの明るさの合計を表す。

Problem Statement

Takahashi is in charge of a library management system. The library has N seats arranged in a single row, numbered 1, 2, \ldots, N from left to right. Each seat faces a long table, and multiple users can sit at the same seat at the same time.

Next, M users will visit the library one by one. The i-th user (1 \leq i \leq M) arrives at time S_i and chooses one seat from the contiguous range of seats from L_i to R_i to sit. Once a user sits down, they do not leave their seat until time T. That is, the number of users sitting at each seat increases monotonically over time.

The seats are chosen as follows. Even if multiple users arrive at the same time, they are processed one by one in the order given in the input (in increasing order of i).

  • Among the seats L_i, L_i+1, \ldots, R_i, choose a seat with the minimum number of currently sitting users, after all the 1-st to (i-1)-th users have already taken their seats.
  • If there are multiple such seats, choose the one with the smallest seat number.

When a user sits down at a seat, the library staff turns on one new desk light to illuminate the user's hands. That is, exactly one light is turned on for each user at the seat they chose, starting at their arrival time.

The brightness of the light turned on at time S_i for the i-th user, at a given time T_0 (where T_0 \geq S_i), is

\max(100 - (T_0 - S_i),\ 0)

That is, the brightness is 100 at the moment it is turned on, decreases by 1 for each unit of time elapsed, and becomes 0 after 100 or more units of time have passed since it was turned on.

Takahashi wants to know the total brightness of the lights at each seat at a specific time T. For each seat 1, 2, \ldots, N, find the sum of the brightness at time T of all the lights turned on at that seat. For seats where no lights are turned on, or where the brightness of all lights has become 0, the total brightness is 0.

Constraints

  • 1 \leq N \leq 2 \times 10^5
  • 1 \leq M \leq 2 \times 10^5
  • 0 \leq T \leq 10^9
  • 0 \leq S_i \leq T
  • 1 \leq L_i \leq R_i \leq N
  • S_1 \leq S_2 \leq \cdots \leq S_M
  • All input values are integers.

Input

N M T
S_1 L_1 R_1
S_2 L_2 R_2
\vdots
S_M L_M R_M
  • The first line contains three space-separated integers: N, the number of seats; M, the number of users; and T, the time at which the brightness is checked.
  • The next M lines describe the users. The i-th line (1 \leq i \leq M) contains three space-separated integers: S_i, the arrival time of the i-th user; L_i, the left end of the preferred seat range; and R_i, the right end of the preferred seat range.
  • The user information is given in ascending (non-decreasing) order of arrival time S_i.

Output

Print N space-separated integers in a single line. The j-th integer (1 \leq j \leq N) should represent the sum of the brightness of the lights at seat j at time T.
