E - 照明スイッチ /

実行時間制限: 2 sec / メモリ制限: 1024 MiB

配点 : 433 点

問題文

高橋君は N 個の照明がある部屋の管理を任されています。各照明には 1 から N までの番号が付けられています。

高橋君の目標は、すべての照明を点灯させることです。

部屋には M 個のスイッチパネルが設置されています。各スイッチパネル j（1 \leq j \leq M）には以下の特性があります：

  • スイッチパネル j には、各照明 i に対して作用するか否かを表す値 b_{j,i} \in \{0, 1\} が定まっている。スイッチパネル j を操作すると、b_{j,i} = 1 であるすべての照明 i の状態が反転する（消えている照明は点き、点いている照明は消える）。b_{j,i} = 0 である照明の状態は変化しない。
  • スイッチパネル j を 1 回操作するたびに、コスト C_j がかかる。

最初、すべての照明は消えています。高橋君は操作を繰り返し行うことができます。1 回の操作では、M 個のスイッチパネルの中から 1 つを選んで操作します。同じスイッチパネルを何度選んでもよく、操作のたびにそのスイッチパネルのコストがかかります。操作の回数に上限はありません。

ただし、この部屋には安全装置が組み込まれています。スイッチパネルを 1 回操作するたびに、その操作の直後の照明の状態が K 個の「危険パターン」のいずれかと一致してはなりません。 危険パターンに一致する状態を経由するような操作は行うことができません。

危険パターンは K 個あり、k 番目（1 \leq k \leq K）の危険パターンは、各照明 i が点灯しているか消えているかを表す値の列 f_{k,1}, f_{k,2}, \ldots, f_{k,N}（f_{k,i} = 1 なら照明 i が点灯、f_{k,i} = 0 なら消灯）として与えられます。

すべての照明が消えている初期状態（すべて 0 の状態）は危険パターンに含まれないことが保証されます。また、すべての照明が点灯している状態（すべて 1 の状態）も危険パターンに含まれないことが保証されます。

危険パターンに一致する状態を途中で経由することなく、すべての照明を点灯させることが可能であるか判定し、可能であれば、そのために必要な最小の合計コストを求めてください。

制約

  • 1 \leq N \leq 18
  • 1 \leq M \leq 20
  • 0 \leq K \leq \min(2^N - 2, 10^5)
  • b_{j,i} \in \{0, 1\}（1 \leq j \leq M、1 \leq i \leq N）
  • 1 \leq C_j \leq 10^6（1 \leq j \leq M）
  • f_{k,i} \in \{0, 1\}（1 \leq k \leq K、1 \leq i \leq N）
  • 危険パターンはすべて異なる
  • すべての照明が消えている状態（すべて 0）は危険パターンに含まれない
  • すべての照明が点灯している状態（すべて 1）は危険パターンに含まれない
  • 答えが存在する場合、答えは符号付き 64 bit 整数に収まる
  • 入力はすべて整数である

  • 1 行目には、照明の数 N、スイッチパネルの数 M、危険パターンの数 K がスペース区切りで与えられる。
  • 2 行目から M + 1 行目には、各スイッチパネルの情報が与えられる。スイッチパネル j の行には、b_{j,1}, b_{j,2}, \ldots, b_{j,N} と C_j がスペース区切りで与えられる。b_{j,i} はスイッチパネル j が照明 i に作用するかを表し、1 なら作用する、0 なら作用しない。C_j はそのスイッチパネルの 1 回あたりの操作コストである。
  • M + 2 行目から M + K + 1 行目には、各危険パターンが与えられる。k 番目の危険パターンの行には、f_{k,1}, f_{k,2}, \ldots, f_{k,N} がスペース区切りで与えられる。f_{k,i} はこの危険パターンにおいて照明 i が点灯している（1）か消えている（0）かを表す。

出力

すべての照明を点灯させることが可能であれば、最小の合計コストを整数で 1 行に出力せよ。不可能であれば -1 を出力せよ。

Problem Statement

Takahashi is in charge of managing a room with N lights. The lights are numbered 1 to N.

Takahashi's goal is to turn all the lights on.

There are M switch panels installed in the room. Each switch panel j (1 \leq j \leq M) has the following properties:

  • Each switch panel j has a predetermined value b_{j,i} \in \{0, 1\} indicating whether it affects each light i. Operating switch panel j toggles the state of all lights i for which b_{j,i} = 1 (lights that are off turn on, and lights that are on turn off). The states of lights with b_{j,i} = 0 do not change.
  • Each operation of switch panel j costs C_j.

Initially, all lights are off. Takahashi can perform operations repeatedly. In each operation, he chooses one of the M switch panels and operates it. The same switch panel can be chosen any number of times, and the cost of the switch panel is incurred for each operation. There is no limit on the number of operations.

However, a safety device is installed in this room. Immediately after each operation, the state of the lights must not match any of the K "dangerous patterns". Operations that result in a state matching a dangerous pattern cannot be performed.

There are K dangerous patterns. The k-th (1 \leq k \leq K) dangerous pattern is given as a sequence of values f_{k,1}, f_{k,2}, \ldots, f_{k,N} representing whether each light i is on or off (f_{k,i} = 1 if light i is on, f_{k,i} = 0 if off).

It is guaranteed that the initial state where all lights are off (all 0) is not included in the dangerous patterns. It is also guaranteed that the target state where all lights are on (all 1) is not included in the dangerous patterns.

Determine whether it is possible to turn all lights on without passing through any state that matches a dangerous pattern. If it is possible, find the minimum total cost required to do so.

Constraints

  • 1 \leq N \leq 18
  • 1 \leq M \leq 20
  • 0 \leq K \leq \min(2^N - 2, 10^5)
  • b_{j,i} \in \{0, 1\} (1 \leq j \leq M, 1 \leq i \leq N)
  • 1 \leq C_j \leq 10^6 (1 \leq j \leq M)
  • f_{k,i} \in \{0, 1\} (1 \leq k \leq K, 1 \leq i \leq N)
  • All dangerous patterns are distinct.
  • The state where all lights are off (all 0) is not included in the dangerous patterns.
  • The state where all lights are on (all 1) is not included in the dangerous patterns.
  • If a solution exists, the answer fits within a signed 64-bit integer.
  • All input values are integers.

Input

The input is given in the following format:

N M K
b_{1,1} b_{1,2} \ldots b_{1,N} C_1
b_{2,1} b_{2,2} \ldots b_{2,N} C_2
\vdots
b_{M,1} b_{M,2} \ldots b_{M,N} C_M
f_{1,1} f_{1,2} \ldots f_{1,N}
f_{2,1} f_{2,2} \ldots f_{2,N}
\vdots
f_{K,1} f_{K,2} \ldots f_{K,N}
  • The first line contains the number of lights N, the number of switch panels M, and the number of dangerous patterns K, separated by spaces.
  • The next M lines (from the 2nd line to the M + 1-th line) contain information about each switch panel. The line for switch panel j contains b_{j,1}, b_{j,2}, \ldots, b_{j,N} and C_j, separated by spaces. b_{j,i} represents whether switch panel j affects light i (1 if it does, 0 if it does not). C_j is the cost per operation of that switch panel.
  • The next K lines (from the M + 2-th line to the M + K + 1-th line) contain the dangerous patterns. The line for the k-th dangerous pattern contains f_{k,1}, f_{k,2}, \ldots, f_{k,N}, separated by spaces. f_{k,i} represents whether light i is on (1) or off (0) in this dangerous pattern.

Output

If it is possible to turn all lights on, print the minimum total cost as an integer in a single line. If it is impossible, print -1.
